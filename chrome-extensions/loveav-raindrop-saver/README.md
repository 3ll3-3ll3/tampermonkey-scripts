# LoveAV 一体化工具

这是一个独立的 Chrome Manifest V3 扩展，把“全局番号过滤器”和“MissAV / 123AV 一键收藏到 Raindrop”放进同一个扩展。两个模块可以分别使用，也可以从网站面板把当前页作品直接送入过滤工作台。

## 一体化工作流

### 四种布局试用版（0.9.0）

在 `chrome://extensions` 重新加载本扩展，确认版本 **0.9.0** 后刷新 MissAV / 123AV 网页。点击左下角 `LoveAV 工具`，在“布局”下拉框切换。四种模式都保留相同的收藏、过滤、首页加载、123AV 顶部推荐和处理状态功能：

| 模式 | 使用方式与取舍 |
| --- | --- |
| 原生侧边栏 | Chrome 为工具分配侧栏，不覆盖网页作品，但网页宽度会减小。Chrome 116+；新增 `sidePanel` 权限。 |
| 独立窗口 | 工具在单独可调整大小的窗口中；不压缩网页，建议拖到屏幕旁边或第二块屏幕。系统窗口仍可能盖住浏览器，需要自己摆放。同一来源重复打开时复用窗口。 |
| 底部停靠 | 网页滚动区与工具栏分开，高度滑块可调；关闭时恢复滚动和位置。会减少网页可视高度，特殊 fixed 导航或播放器仍需要实站体验。 |
| 悬浮收起 | 默认沿用旧入口，保留拖动；鼠标离开约 1.6 秒后收起。展开时仍是悬浮层，适合临时查看，不保证零遮挡。 |

布局偏好保存在扩展本地，下次刷新或新开网页时沿用；不会自动弹出侧栏或窗口。已打开的其他作品页不会被强制换布局。点击左下角入口可重新打开所选模式。独立窗口/侧栏固定连接打开它的来源标签页；“定位来源网页”可以返回该页，不会因你切换浏览器标签而误操作另一个页面。

四个视图控制**同一个来源页执行器**，切换不会重新提交或清空队列；可在网页继续点击 ♥ 追加，待处理列表可移除尚未开始的条目。日志默认折叠，错误自动展开。关闭工具面板不停止任务，也不会被队列下一项强制重新弹出。

**边界：当前仍是按作品标签页保存的临时队列，不是跨标签共享或后台持久队列。刷新、跳转、关闭来源网页会丢失尚未处理的条目；已经提交的请求可能仍完成。** 外部面板断开时明确提示，不会自动重试写入。不要把关掉工具窗口和关闭作品网页混淆。手动番号工作台布局未改动。所有模式复用现有 LoveAV 分类、黑名单、网站标签提取与 Raindrop 查重；不改收藏夹设置。

侧栏遵循 [Chrome Side Panel API](https://developer.chrome.com/docs/extensions/reference/api/sidePanel) 的用户点击开启限制。打开失败会回退悬浮面板并显示原因。Chrome 141 以下切换离开侧栏后可能需要手动点浏览器侧栏关闭按钮。

测试：`layout-modes.test.cjs` 在两站离线页面运行实际 manifest 脚本，覆盖四布局、外部视图控制、队列追加/去重/移除、底栏空间/滚动恢复、旧会话拒绝；`layout-background.test.cjs` 模拟 Chrome API 验证原生入口与窗口复用。没有真实网站收藏写入，也不把模拟原生 API 测试当作用户浏览器实机验收。

### 连续追加收藏与不遮挡面板（0.8.0）

单张卡片或详情页开始收藏后，不再锁住其他作品的快捷收藏入口。继续点击本页其他作品左上角的紫色 `♥`，会按点击顺序加入当前标签页的临时队列；当前作品完成后自动继续。不要导航到下一作品页来追加，整页跳转会销毁当前队列。正在处理或已经排队的相同 URL 不会重复加入，“停止”会终止尚未发出的处理并清空剩余队列。

单条快捷收藏默认只显示紧凑状态条，状态条会显示正在处理及待处理数量，不再自动展开整块日志面板。点击“展开”可查看完整进度、统计和日志；点击“收起”恢复状态条。面板标题栏提供拖动手柄，完整面板也允许调整尺寸。关闭面板不会终止队列，左下角入口会继续显示待处理数量；页面上的卡片 `♥` 在处理和面板打开期间仍可继续点击。

### 全站卡片与推荐收藏（0.7.7）

MissAV / 123AV 不再区分首页与作品页来限制推荐收藏。对于页面已加载、可识别的作品链接：

- 当前作品：详情页保留 `♥ 一键收藏当前作品 · 番号`，只保存当前作品。
- 单张卡片：左上角显示 28×28 像素的紫色 `♥` 小按钮，悬停显示“收藏 番号 到 Raindrop”；同一 URL 同时可见时只放一个快捷按钮，不在标题上重复展示大按钮。
- 板块：打开工具面板 → 选择部分收藏 → 选择板块 → 全选 → 收藏已选。卡片上不再显示“收藏本板块”的大按钮。
- 整页：左下角仅保留“当前作品收藏”（详情页）和“LoveAV 工具”，移除最上方的推荐批量悬浮按钮。展开工具面板仍可一键收藏本页推荐；列表页沿用面板批量收藏。详情页的推荐清单排除当前作品及其同番号链接。
- 自选：详情页同样开放“选择部分收藏”，可按板块、关键词、全选或单个勾选，然后收藏已选作品。

动态加载卡片会重新识别，滚动时按钮随卡片定位。首页、搜索结果、分类、排行、女优列表、侧栏和详情页推荐均复用同一作品链接识别逻辑，不要求页面存在 Load More。仅操作已加载并识别成功的内容；尚未加载的下一页、跨域 iframe 或未知站点链接不会自动遍历。板块按附近标题和卡片结构划分，没有明确标题时归入“其他作品”；批量前可用选择栏核对范围。

所有入口复用原有详情解析、分类、黑名单与 Raindrop 查重，页面加载本身不会自动收藏。0.8.0 起进度面板展开或批次运行时仍保留卡片快捷按钮，用于继续追加待处理。原油猴加载脚本仍保持原用途，不需要额外安装收藏脚本。

### 作品页一键收藏（0.7.5）

MissAV 和 123AV 的具体作品页左下角新增常驻 `♥ 一键收藏当前作品 · 番号`，不必先打开工具面板。包括 MissAV 的 `/dm14/jul-925-english-subtitle`、带语言前缀的作品地址，以及 123AV 的 `/en/v/番号` 等详情页。它只处理当前作品，不会把下面推荐的其他作品一起收藏；即使设置中主按钮为“过滤”，此独立按钮也执行收藏。

点击后打开进度面板，继续使用既有标签解析、分类、两层黑名单语义和 Raindrop 查重流程。已存在、排除或失败都会显示结果；标签为空、标题番号不匹配或页面需要访问验证时不会写入。首页、列表页的批量收藏及 Load More 功能保持不变，页面内切换地址时会重新识别入口。

这是已有“LoveAV 一体化工具”Chrome 扩展的更新，不是另外安装两份收藏油猴脚本。更新本目录后，在 `chrome://extensions/` 重新加载该扩展，再刷新已打开的 MissAV / 123AV 页面。原有授权和设置保留。

### 首页加载工作流（0.7.0）

点击页面左下角 `♥ LoveAV 工具`，展开“首页板块加载 → 选择 / 收藏”。每个 Load More 板块可设置目标总数（1–10000），选择完成后的动作：

- 仅加载：达到目标后停止；
- 加载后勾选（默认）：打开选择栏，勾选整个板块或本次新增作品，手动调整后收藏；
- 加载后自动收藏：达到目标后提交所选范围，目标收藏夹显示在板块设置下方，沿用网站/分类归档设置。

每次运行一个板块，点击间隔至少 900ms；每次等待新增最多 20 秒，连续三次无新增停机。站点按整批返回，实际条数可能超过目标。停止、板块消失、未达到目标就没有更多或加载失败时，不自动收藏；可点“勾选当前板块”处理已有内容。收藏结果在原处理面板中显示。

使用前请停用对应站点的油猴 Load More 脚本并刷新页面。发现其面板或启动入口时，扩展会阻止加载。旧脚本仍保留在仓库。

### 123AV 顶部推荐轮播（0.7.2）

修复每张轮播卡片拥有独立 `.featured` 容器时，只处理第一张的问题：现在整排推荐合并为一个板块，包含隐藏卡片，统一勾选、复制和收藏。兼容单容器、多容器和轮播克隆项。

在首页加载面板中单独显示“顶部推荐轮播”。沿用旧油猴脚本的 `.featured .featured__link` 识别方式，提取页面中包含隐藏项的全部推荐，并按作品 URL 去重。支持“勾选全部推荐”“收藏全部推荐”“提取并复制全部标题”；也可展开完整标题列表，挑选隐藏轮播中的作品，再点“勾选列表中所选”交给统一选择栏收藏。不会点击轮播翻页或下方 Load More，数量以页面实际已存在的推荐为准。

- 默认点击 Chrome 扩展图标打开番号过滤工作台；也可以改为直接收藏当前网页或打开设置；
- 在任意网页打开工作台，粘贴任意长度文字或导入多个文件，按 MissAV Manager v0.5.13 兼容规则过滤、去重、复制或下载番号；
- 可以把过滤结果作为手动番号批次，选择“标准处理、全量重查、只解析预览”后，串行读取 MissAV 候选页面并直接提交 Raindrop；
- MissAV / 123AV 左下角常驻 `♥ LoveAV 工具`，同时保留“收藏到 Raindrop”和“提取并过滤”两个按钮；
- 列表页新增“选择部分收藏”：在作品卡片上勾选，再点击“收藏已选 N 项”；支持全选、反选、按板块选择、选择可见区域、按标题关键词或多行番号勾选；
- 设置页可以选择网站面板的主按钮，并控制工作台是否输入后自动过滤；
- “提取并过滤”只把当前页面已经识别的作品标题和链接传给扩展自己的本地页面，不会写入 Raindrop；
- “收藏到 Raindrop”仍使用 LoveAV 分类、黑名单和查重流程。

## 选择部分作品（0.6.0）

0.6.1：选择栏默认在屏幕底部，使用浏览器顶层显示，避免被网站顶部导航遮挡。可拖动“⠿ 拖动”移动位置，支持收起/展开和重置位置；窗口缩小后自动限制在可见范围内。收起时仍可点击“收藏已选”。

打开 MissAV / 123AV 列表页左下角的 `♥ LoveAV 工具`，点击“选择部分收藏”。页面上方出现选择栏，作品卡片左上角出现复选框。选择栏的板块范围会限制全选、反选、可见区域及关键词操作；“清空全部”清除所有选择。

同一 URL 的重复卡片同步勾选、只提交一次。继续 Load More、替换卡片网格或页面主体时，已选作品保留，新作品默认不勾选。暂时移出页面的已选作品也保留，并显示数量。退出选择后重新打开可继续；刷新或切换到其他页面会清空本页选择。

点击“收藏已选”时固定本次作品清单，只读取这些作品的详情并调用已有分类、查重和 Raindrop 收藏流程。提交进度在原收藏面板显示，目标文件夹沿用已有设置。整页收藏和详情页单个收藏仍可使用。

## 手动番号处理

0.7.3 修复正常 Cloudflare CDN/统计代码被误判成访问验证、导致标签缺失的问题；支持英文 Genre/Category 类型字段。解析日志显示分类、完整标签、目标文件夹和错误原因。遇到真实访问验证、限流或网络错误时整批停止，不自动把读取失败作为“需要查找”写入 Raindrop。确认未找到和元数据待核实的项目仍沿用原分类规则。不会自动覆盖此前已保存的标签。

1. 点击扩展图标打开一体化工作台，把番号或含番号的任意文字粘贴到左侧；
2. 在“手动番号 → MissAV → Raindrop”区域选择模式；
3. 点击“处理并提交 Raindrop”。扩展按 v0.5.13 候选地址顺序逐条验证，番号之间保持 900ms 串行节流；
4. 全部页面解析完成后，统一执行 LoveAV 分类、第二层黑名单、Raindrop URL 查重和批量写入；
5. 处理日志会逐条显示候选地址、解析状态、目标收藏夹及新增/已存在/排除/失败结果。

标准模式会跳过正式主体库已经存在的番号。升级到 0.5.0 后需要在设置页重新导入一次 `missav-library.csv` 和两份黑名单，才能建立本地番号索引。全量重查不跳过主体库，但仍不会重复写入 Raindrop 已有 URL；只解析预览不会写入 Raindrop。

## 行为

0.7.4：MissAV / 123AV 页面收藏与手动番号入口共用标签提取模块，优先读取作品的女优、类型字段，排除导航、男演员和推荐卡片；支持有明确字段标签的不同站点链接结构。保留 LoveAV 的标签清洗、参考匹配、分类优先级及两层黑名单语义。页面收藏日志显示实际提交的标签与分类；标题番号不匹配、访问验证、读取失败或元数据标签为空时阻止整批提交，不再静默写入错误标签。更新不会覆盖已有收藏。

- Raindrop 标题使用标准化番号，完整网页标题保存在摘要中；
- 默认按来源网站归档：MissAV → `MissAV`，123AV → `javxxx&123av`；这两个收藏夹可以位于 Raindrop 子目录中；
- LoveAV 分类优先级仍为：`需要查找` → `参考女优Tag命中` → `其他`，分类结果保留为标签判断与处理信息；
- 命中 `2-Raindrop导出黑名单.txt` 时不保存；
- 保存前使用 Raindrop 官方接口检查 URL，已存在的作品不重复写入；
- 批量查重采用分组定位，新增数据按分类分组并以每批最多 100 条写入；
- OAuth 令牌到期前自动刷新；
- 每个 MissAV / 123AV 页面左下角都会常驻显示 `♥ LoveAV 工具` 入口，不再因为暂时未识别到作品而消失；
- 点开后可查看识别、详情解析、分类、查重、新增、排除和失败的逐条进度；
- Chrome 工具栏扩展图标的行为可在设置页切换；
- 缺少目标收藏夹时，默认自动创建同名的私人收藏夹。

## 安装

1. Chrome 打开 `chrome://extensions/`；
2. 开启“开发者模式”；
3. 选择“加载已解压的扩展程序”；
4. 选择本目录 `chrome-extensions/loveav-raindrop-saver`；
5. 首次安装会自动打开设置页。若是从旧版升级，在 `chrome://extensions/` 中点一次“重新加载”即可保留原来的本机 OAuth、规则和收藏夹设置。

升级并确认一体化工具正常后，原来的独立“全局番号过滤器”扩展可以停用，以免工具栏出现两个相似入口；仓库仍保留其源码作为独立版本。

## 首次设置

### 1. 导入 LoveAV 规则

在设置页选择包含以下文件的 `LoveAV-Data` 或 `missav` 文件夹：

- `missav-library.csv`
- `1-参考女优Tag库黑名单.txt`
- `2-Raindrop导出黑名单.txt`

扩展只在浏览器本机解析这些文件，然后把派生规则保存到 `chrome.storage.local`。私人主体库、黑名单及派生结果均不在本仓库中。

### 2. OAuth 授权

Raindrop 官方 OAuth 要求应用的 `Client ID` 和 `Client Secret`。在 [Raindrop App Management Console](https://app.raindrop.io/settings/integrations) 创建个人应用，把设置页显示的 redirect URI 填入该应用，再在本机设置页输入两项应用凭据并授权。

Client Secret、access token 与 refresh token 只保存在本机扩展存储，不会写入源码、日志或 Git。此方式适合个人自用；如果将扩展公开分发，应把 token 交换迁移到受控后端，不能在分发包中内置 Client Secret。

### 3. 收藏夹映射

默认启用“按网站归档”，目标收藏夹名称为：

- MissAV：`MissAV`
- 123AV：`javxxx&123av`

设置页也可以切换回“按 LoveAV 分类归档”，其三个目标收藏夹为：

- `参考女优Tag命中`
- `需要查找`
- `其他`

如果 Raindrop 中有重名收藏夹，可在设置页查看收藏夹 ID，并为对应分类填写唯一 ID。

## 大批量性能

列表页会读取当前 DOM 中已经加载的全部作品，以 4 个并发请求补齐作品详情，然后批量查重和分类。新增作品按 Raindrop 官方上限每 100 条调用一次 `POST /rest/v1/raindrops`，不会为每一条新增作品单独发起写入请求。
