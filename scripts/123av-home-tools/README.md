# 123AV 首页工具

适用于 `https://123av.com/cn` 及 123AV 其他语言版首页的 Tampermonkey 脚本。

## 功能

- 一键提取顶部轮播的全部标题，不用手动翻页。
- 提取结果自动复制到剪贴板，并在面板内显示。
- 自动识别首页上所有带“加载更多”的板块。
- 每个板块可单独设置目标数量、开始和停止。
- 支持全部开始、全部停止、失败重试和自动停机。
- 多个板块串行加载，降低频率过高造成限流的风险。

## 2026-09-08 页面验证

- 顶部轮播：20 个标题，全部已存在于 DOM，可一次提取。
- Load More 板块：4 个，当前为“为您推荐、Solowork、乳液/油、屁股恋物癖”。
- 每个板块首屏 4 条；实测单击一次从 4 增长到 12，即通常增加 8 条。

板块名称和数量会在运行时动态识别，不依赖上述四个固定名称。

## 安装

在 Tampermonkey 中安装 `123av-home-tools.user.js`。脚本默认不会主动显示面板；需要使用时，
点击浏览器工具栏中的 Tampermonkey 图标，再选择“打开/隐藏 123AV 首页工具”。面板右上角的
`×` 会停止任务并隐藏面板，之后可从油猴菜单再次打开。

## 构建与检查

```powershell
node .\build-userscript.mjs
node --check .\123av-home-tools.user.js
```

## 停止规则

- 当前卡片数达到或超过目标。
- 加载按钮消失或长时间不可用。
- 连续 3 次、每次 20 秒都没有新增内容。
- 用户点击停止。

大批量加载会增加页面内存占用，建议先以 100 条试运行，再逐步增加。
