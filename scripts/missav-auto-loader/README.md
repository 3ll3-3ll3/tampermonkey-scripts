# MissAV Auto Load More

这是一个只操作当前 MissAV 页面已有 `Load more` 按钮的本地辅助脚本。它不会登录、收藏、上传或写入 LoveAV 主体库。

当前页面会自动识别每个带 `Load more` 的板块，并分别提供：

- 当前卡片数；
- 目标总数；
- 单独开始、单独停止；
- 全部开始、全部停止；
- 无新增重试与自动停机。

## 推荐使用：Tampermonkey 本地联动

安装 `missav-auto-loader.user.js`。它是完整内嵌安装包，不依赖
`file://` 权限。当前版本为 `1.5.0`，使用油猴沙箱运行，避免站点 CSP 阻止脚本启动；
同时会等待页面异步内容出现、按按钮与实际卡片网格的 DOM 关系识别板块，并自动更新各板块的真实标题。
Chrome 138 及以上需要在 Tampermonkey 扩展详情页打开“允许用户脚本”。

脚本默认静默运行，不会主动弹出面板。需要使用时，点击浏览器工具栏中的 Tampermonkey
图标，再选择“打开/隐藏 MissAV Load More 面板”。面板右上角的 `×` 会停止任务并隐藏面板。

以后 Codex 修改 `missav-auto-loader.js` 后，运行 `node build-userscript.mjs` 生成新版安装包，
再由用户在 Tampermonkey 更新确认页点击一次“更新”。

## 临时使用

1. 打开 MissAV 对应页面并等待首屏加载完成。
2. 在该页面的开发者工具 Console 中粘贴 `missav-auto-loader.js` 的完整内容并回车。
3. 在右上角面板中，为每个板块填写目标总数，然后分别点“开始”，或点“全部开始”。
4. 导航或刷新页面后脚本会消失，需要重新运行。

控制台版本会直接显示面板。同一页重复执行脚本不会创建第二个面板，只会显示并刷新已有面板。

## 停止规则

- 当前卡片数达到或超过目标；
- `Load more` 按钮消失或长期不可用；
- 连续 3 次、每次 20 秒均没有新增卡片；
- 用户点击停止。

MissAV 当前桌面布局每次通常增加 3 行、每行 4 条，因此目标不是 12 的步长时，最终数量可能最多多 11 条。大批量加载会明显增加页面内存占用；建议先试 100，再逐步提高到 500 或 1000。

## 内置浏览器说明

若 Codex 内置浏览器没有向你提供开发者工具 Console，不能直接把脚本永久注入该浏览器。此时可以直接告诉 Codex四个板块各自的目标数，由 Codex 使用页面自动化按相同停止规则执行；或者在支持开发者工具的 Chrome 页面运行本脚本。
